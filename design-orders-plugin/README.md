# پلاگین سفارشات طراحی (Design Orders Plugin)

پلاگین کاملی برای ووردپرس و ووکامرس که امکان سفارش طراحی را فراهم می‌کند و با قالب Woodmart سازگار است.

## ویژگی‌های کلیدی

### 🎨 سیستم سفارش طراحی
- چک باکس "سفارش طراحی" زیر هر محصول در mini cart
- پاپ اپ زیبا و کاربرپسند برای ثبت جزئیات سفارش
- ثبت خودکار سفارش با وضعیت "در انتظار پرداخت"
- اضافه شدن محصول سفارش طراحی به سبد خرید

### 🔧 پنل مدیریت
- منوی "سفارشات طراحی" در پنل ادمین
- صفحه مشاهده و مدیریت سفارشات
- صفحه تنظیمات (قیمت و ایمیل اطلاع‌رسانی)
- امکان تغییر وضعیت سفارشات
- جدول کامل با امکان فیلتر و جستجو

### 📧 سیستم اطلاع‌رسانی
- ارسال ایمیل به ادمین هنگام ثبت سفارش جدید
- اطلاع‌رسانی پرداخت و شروع پروژه
- قالب‌های ایمیل RTL و زیبا

### 🛒 تغییرات Mini Cart
- جایگزینی دکمه‌های پیش‌فرض با دکمه "ثبت سفارش"
- هدایت مستقیم به صفحه پرداخت

## نصب و راه‌اندازی

### پیش‌نیازها
- ووردپرس 5.0+
- ووکامرس 5.0+
- PHP 7.4+

### مراحل نصب
1. فایل‌های پلاگین را در پوشه `/wp-content/plugins/design-orders-plugin/` آپلود کنید
2. از طریق پنل ادمین ووردپرس پلاگین را فعال کنید
3. به صفحه **سفارشات طراحی > تنظیمات** بروید
4. قیمت سفارش طراحی و ایمیل اطلاع‌رسانی را تنظیم کنید
5. گزینه "فعال‌سازی سفارشات طراحی" را فعال کنید

## نحوه استفاده

### برای مشتریان
1. محصولات مورد نظر را به سبد خرید اضافه کنید
2. در mini cart، چک باکس "سفارش طراحی" را برای محصول مورد نظر انتخاب کنید
3. در پاپ اپ باز شده، جزئیات سفارش و ایمیل خود را وارد کنید
4. سفارش طراحی ثبت می‌شود و محصول مربوطه به سبد اضافه می‌شود
5. برای تکمیل فرآیند، سفارش را پرداخت کنید

### برای مدیران
1. از منوی **سفارشات طراحی > مشاهده سفارشات** تمام سفارشات را ببینید
2. وضعیت سفارشات را تغییر دهید:
   - **در انتظار پرداخت**: سفارش ثبت شده اما پرداخت نشده
   - **در انتظار اجرا**: سفارش پرداخت شده و آماده شروع کار
   - **تکمیل شده**: پروژه تمام شده
   - **لغو شده**: سفارش لغو شده
3. از بخش تنظیمات، قیمت و ایمیل اطلاع‌رسانی را مدیریت کنید

## تنظیمات پیشرفته

### تغییر قیمت پیش‌فرض
```php
// در فایل functions.php قالب
add_filter('design_orders_default_price', function($price) {
    return 100000; // قیمت به تومان
});
```

### تغییر متن‌ها
```php
// تغییر متن دکمه
add_filter('design_orders_submit_button_text', function($text) {
    return 'سفارش طراحی من';
});
```

### هوک‌های موجود
```php
// قبل از ثبت سفارش
do_action('design_orders_before_insert', $order_data);

// بعد از ثبت سفارش
do_action('design_orders_after_insert', $order_id, $order_data);

// تغییر وضعیت سفارش
do_action('design_orders_status_changed', $order_id, $old_status, $new_status);
```

## عیب‌یابی

### مشکلات رایج

**چک باکس نمایش داده نمی‌شود:**
- از فعال بودن پلاگین اطمینان حاصل کنید
- گزینه "فعال‌سازی سفارشات طراحی" را در تنظیمات چک کنید
- کش مرورگر را پاک کنید

**پاپ اپ باز نمی‌شود:**
- JavaScript errors را در console مرورگر بررسی کنید
- از وجود jQuery در سایت اطمینان حاصل کنید
- تداخل با سایر پلاگین‌ها را بررسی کنید

**ایمیل ارسال نمی‌شود:**
- تنظیمات SMTP سرور را بررسی کنید
- از صحت ایمیل اطلاع‌رسانی در تنظیمات اطمینان حاصل کنید

### لاگ‌ها
فایل لاگ در مسیر `/wp-content/debug.log` قرار دارد.
